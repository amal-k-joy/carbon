## Overview

The CoachmarkStacked is a **pattern** (not a component) that provides a recipe
for building a fixed, layered coachmark interface. It appears fixed at the
bottom-right corner of the browser window. The home layer can contain ghost
buttons to open a second, stacked layer that slides up on top of it — similar
to a stacked Tearsheet. When dismissed, the stacked layer slides back down to
reveal the home layer, which can then be dismissed to slide off the page.

## What is a Pattern?

Unlike components that are exported from the package, **patterns are recipes**
that you copy into your codebase and customize to fit your specific needs. This
approach offers:

- **Full Control**: Modify the code to match your exact requirements
- **No Breaking Changes**: Updates to the pattern don't affect your
  implementation
- **Seamless Customization**: Adapt the pattern without workarounds or prop
  drilling
- **Scalability**: Build upon the foundation with your own features

## Getting Started

1. **Copy the pattern code** from the
   [example directory](https://github.com/carbon-design-system/carbon/tree/main/packages/react/src/examples/Coachmark/CoachmarkStacked/example/components)
   into your project
2. **Install dependencies**: `@carbon/react`, `@carbon/ibm-products`,
   `@carbon/utilities`
3. **Import and use** the pattern component in your application
4. **Customize** as needed for your use case

The pattern uses:

- **Coachmark component** (preview, `@carbon/ibm-products`): Provides the
  popover container and tagline
- **Carousel utility** (`@carbon/utilities`): Manages multi-page content
  within a stacked layer
- **Carbon React components**: `Button`, `Link`, `Theme` for UI elements

```jsx
import { Button, Theme, Link as CarbonLink } from '@carbon/react';
import {
  preview__CoachmarkTagline as CoachmarkTagline,
  preview__Coachmark as Coachmark,
} from '@carbon/ibm-products';
import { InitCarousel, initCarousel } from '@carbon/utilities';
```

### Key Features

- **Fixed positioning**: Anchored to the bottom-right corner of the viewport
- **Stacked layers**: A home layer hosts navigation links that open individual
  stacked coachmarks
- **Carousel support**: Each stacked layer can contain multi-page carousel
  content
- **Animated transitions**: Layers slide in/out with Carbon motion tokens
- **Focus management**: Keyboard focus returns to the triggering element on
  close
- **Theme aware**: Reads the current Carbon theme from `data-carbon-theme`
